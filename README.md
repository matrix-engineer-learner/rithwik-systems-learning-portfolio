### 🧠 Operational Strategy & Creative Process
This portfolio is driven by a desire to explore how complex machine learning matrices and network pipelines behave in the real world. 

Instead of focusing on memorizing standard syntax rules or debugging raw code strings, my approach centers on acting as a **Systems Architect**. I design the layout workflows, choose the environmental inputs, and structure the data flow logic. I intentionally use Generative AI tools as an advanced engineering lever to write the core code templates and handle background script execution, keeping the primary focus on systems logic and execution strategy.
